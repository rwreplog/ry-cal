# UI Design

## Personality
A polished smart-home dashboard made specifically for one family.

## Dashboard priorities
1. Today
2. Upcoming events
3. Incomplete chores
4. Important announcements
5. Secondary information

## Visual language
Prefer:
- Large typography
- Rounded cards
- Generous spacing
- Clear icons
- Strong hierarchy
- Subtle depth
- Subtle animation

Avoid:
- Dense tables
- Tiny text
- Generic enterprise styling
- Excessive borders
- Excessive decoration

## TV readability
At roughly 10 feet, users should be able to determine:
- Current time
- Current day
- Next calendar event
- Who has chores
- Important announcements

## Mobile
Common actions such as completing a chore should require very few taps.

Respect `prefers-reduced-motion`.
